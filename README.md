# 🎓 Student Management System

A Python-based **Student Management System** built as part of my Python Internship Capstone Project. This project focuses on implementing authentication, role-based access control, CRUD operations, data persistence, and clean software architecture while following industry-standard development practices.

---

## 📌 Project Overview

The Student Management System is a Command Line Interface (CLI) application that allows administrators to securely manage student records.

The project is being developed in phases:

* **Phase 1:** Python CLI Application (Internship Requirement)
* **Phase 2:** Enhanced Features for Data Science
* **Phase 3:** FastAPI Backend
* **Phase 4:** React Frontend
* **Phase 5:** Analytics Dashboard

---

## 🚀 Features

### Authentication

* User Registration
* User Login
* User Logout
* Password Hashing (SHA-256)
* Session Management
* Role-Based Access (Admin & Student)

### Student Management (CRUD)

* Add Student
* View All Students
* Search Student
* Update Student
* Delete Student

### Data Management

* JSON-based Data Persistence
* Automatic Data Loading on Startup
* Input Validation
* Exception Handling
